## How to use this file

- Append a row when you do something that future-you (or a fresh session) needs to know about.
- Keep each cell to one or two short sentences. The point is scanability, not detail.
- "Did" is past tense, concrete. "Observing" is the signal or data, not vibes. "Look for" is the open thread or watch item.
- Move items from "Open threads" into the main table when they get acted on (with a date row for the action).
- Don't backfill more than one session in either direction — the file is for the active development arc, not the whole history.
