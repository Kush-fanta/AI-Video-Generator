# Web Research

Use this file when the `director` skill needs to browse for references on demand.

## When To Browse

Browse when any of these are true:
- the piece needs current references or present-day texture
- the story depends on a real place, real event, or real subculture
- you need regional detail instead of generic global aesthetics
- the user wants references, comparisons, or a research-backed board canvas
- a visual or tonal choice is weak because it is based on memory instead of evidence

Do not browse just to decorate the answer.

## What To Look For

Find only what changes the decision:
- visual references
- director or cinematographer interviews
- location texture
- costume, architecture, or object detail
- documentary or archival material
- current headlines, trends, or platform-native examples when the board direction depends on the present

Collect three to seven strong references, not fifty tabs of moodboard noise.

## Source Order

Start with the strongest source available:

1. Primary sources
- official interviews
- archives and museums
- film festival notes
- production-company materials
- local journalism
- public institutions and cultural organizations

2. Strong craft/editorial sources
- `bfi.org.uk`
- `criterion.com/current`
- `mubi.com/en/notebook`
- `blog.frame.io`
- `ascmag.com`
- `sensesofcinema.com`

3. Fast texture sources
- local photo essays
- tourism and civic sites
- public domain image collections
- region-specific press

If the topic is current, verify dates and avoid leaning on stale references when newer evidence exists.

## Useful Search Patterns

Use narrow, problem-shaped searches:

- `site:criterion.com/current Claire Denis interview intimacy`
- `site:mubi.com/en/notebook Kiarostami actors minimal direction`
- `site:bfi.org.uk Hitchcock storyboard suspense`
- `site:blog.frame.io animatic storyboard pre edit sequence`
- `site:ascmag.com [film title] cinematography interview`
- `site:sensesofcinema.com [director name] mise en scene`
- `site:[local news or culture domain] [city or region] photo essay`

For regional work, search in or around the language of the place when possible.

## Output Shape

When the research is non-trivial, return a compact brief:
- question
- reference list
- what each reference solves
- the directorial decision it supports
- any risks or uncertainty

The output should help Varnam decide, not just collect.

## Rules

- search globally, not just in English-language or Hollywood-centric sources
- prefer material from the culture, place, or craft tradition closest to the story
- do not copy one existing film whole
- use references to sharpen authorship, not replace it
- if the web is unavailable, fall back to local guides and say what is missing
