# Formats

Format guides hold reusable behavior for how a piece works as a piece.

They are not channel taste.

- `channels/<name>/...` = how this channel tastes
- `formats/<name>.md` = how this format behaves
- `projects/<slug>/task-config.md` = which parts of both are active for this film

Use a format guide when the piece changes its screen logic, compression pattern, hook shape, or narrative movement in ways that should survive across channels.

Do not put palette, font, voice adjectives, or channel-specific frame vocabulary here.
