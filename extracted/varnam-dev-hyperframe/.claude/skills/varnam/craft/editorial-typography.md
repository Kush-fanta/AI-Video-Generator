# Editorial Typography

Editorial typography governs how text behaves on screen as information, emphasis, and editorial voice.

For Varnam, this is not font picking. It is the craft of making words readable, hierarchical, and compatible with image, motion, and caption space.

## First Principles

1. **The first read must be obvious.** Typography should tell the eye where to land first.
2. **Hierarchy comes before style.** Size, weight, placement, and contrast matter before ornament.
3. **Text shortens scan time.** On-screen words should help the viewer read the frame faster, not slower.
4. **Different text jobs need different systems.** Headlines, labels, quotes, facts, subtitles, citations, and lower-thirds should not behave as one undifferentiated layer.
5. **Respect safe areas and collisions.** Text must coexist with captions, images, charts, and logos without fighting them.
6. **Density is a design decision.** If the viewer must read too much, the visual system failed upstream.
7. **Do not transcript the narration.** On-screen text is editorial text, not karaoke.

## Typography Tests

### Hierarchy Test

Can the viewer tell in a glance what is primary, secondary, and supporting?

### Collision Test

Does the text avoid competing with captions, key imagery, and essential labels?

### Readability Test

Would the text still read clearly at reduced size and short hold durations?

### Category Test

Is each piece of text behaving according to its job, not just using a reused style?

## Failure Modes

Reject the typography if it becomes:
- subtitle wallpaper
- one-style-fits-all text
- dense cards that require pausing
- decorative type that weakens clarity
- text stacked into image conflict
