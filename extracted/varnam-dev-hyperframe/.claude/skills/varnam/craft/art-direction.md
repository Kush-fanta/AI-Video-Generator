# Art Direction

Art direction governs the visual world of the piece.

For Varnam, it decides how footage, stills, graphics, maps, typography, and generated media all feel like they belong to the same publication and the same argument.

## First Principles

1. **Build one coherent world.** Palette, texture, image treatment, and object language should feel like one system, not a collage of local decisions.
2. **Choose medium for argumentative value.** Real media proves, graphics explain, generated media fills what cannot otherwise be shown.
3. **Style must serve the claim.** The visual world should sharpen the argument, not sit beside it as mood wallpaper.
4. **Consistency beats isolated beauty.** One stunning frame in the wrong world weakens the film.
5. **Treat surfaces, not assets.** Photography, illustration, archival media, and diagrams all need a common treatment logic.
6. **Use contrast deliberately.** Dark/light, rough/clean, dense/spare, and warm/cold are structural decisions, not decoration.
7. **Novelty is not permission.** If an image treatment does not clarify tone, period, or meaning, cut it.
8. **Abstract metaphor is valid when it explains nature, not appearance.** Show what a thing means when literal depiction is weaker than visual interpretation.

## Art Direction Tests

### World Test

Do the assets feel like they came from the same publication and the same film?

### Medium Test

Is each medium doing the job it is best suited to do?

### Treatment Test

Would a new asset dropped into this piece know how to behave?

## Failure Modes

Reject the art direction if it becomes:
- asset collage
- generic cinematic mood
- generated-image sameness
- archival drops with no treatment logic
- palette noise with no role discipline
