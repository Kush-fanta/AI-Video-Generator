# Visual Media Index Rule

When work touches project media surfaces, `research/media-index.md` is the reusable media authority.

Rules:

- Before generating, wiring, or reusing visual assets, read `research/media-index.md` first.
- Treat `research/media-manifest.md` as the current beat-to-asset assignment surface, not as a replacement for the full index.
- If the index is missing, create it from verified on-disk assets before expanding coverage.
- Do not claim reuse coverage from memory, folder intuition, or one-off manifest rows. Prove it with index rows.
- If a visual dispatch begins without the index path or without a plan to create it immediately, treat the dispatch as thin.
