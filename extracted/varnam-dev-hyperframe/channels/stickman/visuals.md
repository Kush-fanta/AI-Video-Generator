# Stickman - Visuals

MS Paint meets whiteboard meets conspiracy board. Deliberately crude, aggressively legible, never polished.

## Core Principle

If the narrator says it, the board should show it. Nothing important lives in audio alone.

## Visual World

The whiteboard is the stage, the notebook, and the joke.

- stick figures as minimal characters
- hand-drawn arrows, circles, underlines, and cross-outs
- crude maps, timelines, money stacks, counters, and labels
- occasional absurd generated image only for the biggest punchline

## Layout Discipline

The frame behaves like a real whiteboard:

- center for main action
- margins for side annotations
- bottom for running gags or counters
- a corner reaction only when it helps the beat

Do not let elements collide. If the board is full, wipe or move before adding more.

## Motion

- draw-on lines and arrows
- pop-in arrivals, not soft fades
- zoom slams for hero numbers
- quick wiggle or shake on impact beats
- longer held whiteboard builds for complex concepts

## Evidence Rule

Real photos, maps, and headlines are valid when they prove something. Give them the same whiteboard treatment: rotation, arrows, circles, labels.

Generated absurd images are rare. Use them for 2-3 major joke beats per video, not as a default visual mode.
