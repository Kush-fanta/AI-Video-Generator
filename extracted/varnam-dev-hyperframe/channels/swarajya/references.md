# Swarajya — Reference Library

Observed patterns from Swarajya's actual produced output, studied to sharpen the designed taste we're building for the channel. The channel does not have a locked house style yet — its current output is experimental. `design.md` defines what we are establishing; references are mined for **transferable patterns** (density, cadence, abstraction handling), not aesthetic cloning.

---

## Round 1 — "The Silent Fleet: How India Built Nuclear Submarines in Secret"

- URL: https://www.youtube.com/watch?v=gPIKnV-kjgY
- Duration: 15:50
- Views at study: 180,434
- Format: long-form explainer, VO-led

### What the reference ships as

- Canvas: dark navy, white/red type — this is the baseline register to preserve.
- VO: single narrator, no host on camera.
- Modes observed: archival video, archival photo, modern b-roll footage, portrait photo, type card, stat card, chart, map, diagram, split photo+text, label stamp.

### Transferable finding 1 — Media density

| Metric | Observed |
|---|---|
| Distinct photographs | ~25 |
| Distinct video clips (archival + b-roll) | ~60 |
| Data viz beats (chart / map / diagram / comparison) | ~10 |
| Pure type cards | ~20 |
| **Total media beats in 15:50** | **~115 — one new visual every ~8 seconds** |
| Average frame duration | 3–6 seconds, modal 4–5s |
| Longest pure-type stretch in the entire film | 17 seconds, and it was a single card held deliberately |

**Ledger entry:** recorded in `channels/swarajya/ledger.md` as a measured performance band, not as identity.

### Transferable finding 2 — How abstraction is visualized

The reference never carries an abstract argument on type alone. When the beat is policy, strategy, technical backstory, or an analogy, it visualizes the referent — not the metaphor.

| Abstract beat | On-screen |
|---|---|
| Geopolitical threat (US intervention, 1971) | Archival footage of the actual aircraft carrier (USS Enterprise) |
| Technical analogy ("scooter mechanic building a Mercedes") | Engineers working on real precision machinery — the referent of the comparison, not the metaphor object |
| Program secrecy / invisibility | Wide shot of the actual dry dock, 50m underground |
| Strategic doctrine (nuclear triad) | Clean numbered type card: 01 Land / 02 Air / 03 Sea |
| Program failure ("Dead. — by any honest assessment") | Single-word type card as punctuation, held |

**Rule extracted to craft/storyboarding.md:** abstraction-visualization pattern library (threat → physical object, analogy → referent, secrecy → place, doctrine → list, death → single-word).

### What we are NOT adopting

- B-roll from own camera shoots — "No host, no camera" stays; archival and licensed b-roll is the media source
- Their frame vocabulary as-is — our canonical family stays, extended with archival video / b-roll / label-stamp

### Study method

Downloaded via yt-dlp, tiled 95 frames (1 per 10s) into a mosaic for scan-pass, uploaded full file to Gemini 2.5 Pro via API key for structured rotation table. Both passes agreed on the density finding.
